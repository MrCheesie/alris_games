AI Harness

Setting up an API key:

This next section will guide you through setting up the AI harness with google’s API.

  1. Go to settings (Gear icon on the top right of the screen)

  2. Then Change the provider to Google and change the endpoint to 

https://generativelanguage.googleapis.com/v1beta/openai/
  1. Navigate to Google AI Studio and get your free API key from there.
  2. Paste the API key into the AI harness.
  3. Close settings
  4. Select a model from the model picker in the top left corner (the Flash models are free)
  5. Enjoy your chat
