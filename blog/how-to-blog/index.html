How to Blog

A guide on how to make your own blog in alris’ games.

12 • 9 • 2026 | Alris Dhanwani

This blog will guide you through how to make your very own blog in alris’ games.

Requirements

Your blog requires the following things:

  • Title (e.g.: How to Blog)
  • Subtitle/extended title/description (e.g.: A guide on how to make your own blog in alris’ games.)
  • Date written
  • Author
  • Website url (e.g.: how-to-blog) (comes after https://mrcheesie.github.io/alris_games/blog, so the full name will be https://mrcheesie.github.io/alris_games/blog/your-custom-blog-url) The URL must NOT contain spaces, and can only contain number, lowercase letters, underscores and hyphens
  • Content - The actual blog

Blog formats

Since the blog is a website, if you want no or minimal changes to your blog, write it in an HTML format. If you prefer not to, however, then the following formats are also accepted, but may have some changes.

  • Markdown - .md, .markdown
  • Rich text documents - .rtf, .odt, .docx
  • Plain text - .txt

All of these formats are converted to HTML using Pandoc. Blogs support both web images and local images in all formats.

Submitting

To submit your blog to me, email me at alrisdhanwani@protonmail.com with your file attached. If you have external photos and are using markdown or HTML, send a .zip file with your blog and the images inside. It is recommended your blog have a sources section for topics you have researched for.
