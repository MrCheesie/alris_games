# Contribution guidelines

You must follow this policy if you wish to contibute.

- No harmful games/tools
- No inappropriate content
- Approved by owner of the repo
- Licensed under one of the following (if your game does not have a seperate GitHub repo, please attach the license in the game folder or specify in `details.json`:
  - Apache 2.0 (recommended)
  - MIT
  - BSD
  - The Unlicense
